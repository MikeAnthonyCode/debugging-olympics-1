# Debugging Olympics

## Introduction

This is a competition to test your debugging skills. You will be given a game with bugs and you need to fix these bugs. Make sure to read the error messages. On some of the tasks there won't be an error message but the game won't function correctly.


## Acceptance Criterea
If the game is functioning properly the following features and flow should be working:
1. Start the game
2. Give an answer
3. His score should go up by 1 on each question
4. He can restart the game and play again with his score reset as well


## Set Up Instructions

Create a folder called `debugging-olympics-1` in your `lectures` folder. Inside the `debugging-olympics-1` folder create 3 files:
1. `index.html`
2. `app.js`
3. `style.css`

In this repository you have all 3 completed files so copy the contents of each into the files.

There are 7 issues with the code. Try to get as many as you can.



## Scoring

Each bug is worth 5 points. In total there are 7 bugs in this code. Bonuses are worth 3 points each. The bonuses are listed below:

### Bonuses
- Bonus 1: Commits for each task done. meaning after each task is done you commit that change with a <b>clear commit message</b>.
- Bonus 2: show the correct answer when the user gets the question wrong
- Bonus 3: When the user gets a question correct the “Correct!” message should disappear after 3 seconds





## Contrains

You will have 45 minutes to finish the exercise. Once you are finished push the code to github (only 1 person in the group to submit).
